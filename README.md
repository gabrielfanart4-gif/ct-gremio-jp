# CT Grêmio JP — instaladores do aplicativo

Este repositório existe por **um** motivo: hospedar o instalador Android do
aplicativo do CT Grêmio JP num endereço público e permanente.

Não há código-fonte aqui. O app vive em repositório próprio, privado.

## Baixar

**[Baixar a versão mais recente](https://github.com/gabrielfanart4-gif/ct-gremio-jp/releases/latest/download/ct-gremio-jp.apk)**

Esse endereço aponta sempre para a última versão publicada — não muda quando
sai uma atualização.

Prefere não instalar nada? O app roda no navegador, com a mesma conta:
**[app.ctgremiojp.com.br](https://app.ctgremiojp.com.br)**

## Como instalar

1. Baixe o arquivo pelo link acima
2. O Android vai avisar que o arquivo veio de fora da Play Store — é esperado,
   já que a distribuição é direta. Toque em **Instalar assim mesmo**
3. Se pedir permissão para "instalar apps desconhecidos", conceda ao navegador
   que você usou para baixar

## Atualizações

Baixe a versão nova pelo mesmo link e instale por cima. **Não desinstale a
anterior** — instalar por cima preserva seus dados.

Todas as versões são assinadas com a mesma chave. Se algum dia uma instalação
por cima for recusada, é sinal de que o arquivo não veio daqui.
